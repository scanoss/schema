# SCANOSS Schemas

A centralized collection of all SCANOSS schemas, which are central to all our applications and tools.

This repository serves as the single source of truth for the schema definitions used across the SCANOSS ecosystem, ensuring consistency and interoperability between all SCANOSS components.

## Schemas

| Schema | Description |
|--------|-------------|
| [scanoss.json](scanoss.json.md) | Configuration file schema used by SCANOSS tools for scanning settings, policies, and BOM management |

## Usage

Refer to the individual schema documents for detailed structure, field descriptions, and examples. These schemas define the configuration formats accepted by SCANOSS tools such as [scanoss.py](https://github.com/scanoss/scanoss.py) and other integrations.
